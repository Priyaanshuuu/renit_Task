# Future scope

## First improvements

1. Agree the real decision cutoff and delivery-day convention with the client.
2. Extend the historical period to check seasonal performance.
3. Automate data updates and show freshness warnings.
4. Let users compare forecast accuracy at different decision times.
5. Add validated historical uncertainty ranges when enough data exists.

## If the client expands the scope

- Add customer demand and existing purchase contracts to estimate the client's remaining requirement.
- Add the client's renewable generation allocation; national wind is not automatically available to this utility.
- Add electricity prices to study financial exposure, using clearly stated assumptions.
- Add other renewable sources, such as solar, and assess them separately.
- Add saved scenarios, user accounts, and an audit trail if multiple buyers use the product.

These additions require data beyond the two Elexon datasets allowed in the assignment. Keep them out of the submitted pilot unless explicitly approved.

## How to decide what comes next

Ask the buyer which decision is still difficult after using the pilot. Build the smallest feature that improves that decision, and validate it with real users before adding more infrastructure.
